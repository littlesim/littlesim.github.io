# Komplek Raka

Game 3D dari **Little Sim**. Jalan-jalan keliling komplek sebagai Raka, mampir ke rumah tetangga, main congklak, mancing di danau, dan cari 16 keanehan yang disembunyikan.

**▶ Main di sini: [littlesim.github.io](https://littlesim.github.io)**

Bisa dimainkan langsung dari browser, di HP maupun laptop.
